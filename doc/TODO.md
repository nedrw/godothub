## 📝 开发笔记

### 当前工作重点
1. **UI 优化** - 优先优化侧边栏和版本面板的用户体验
2. **下载功能** - 实现真实的 GitHub API 集成
3. **项目扫描** - 完善项目管理功能

### 技术债务
- 需要重构 AppState 以更好地分离关注点
- 下载服务需要完整的错误处理
- UI 组件需要更好的可测试性
- 需要添加单元测试和集成测试

### 设计决策
- 使用 egui 的原生风格，不引入额外的样式库
- 优先保证功能完整性，再考虑美观性
- 使用异步处理避免 UI 阻塞
- 配置文件使用 JSON 格式便于人工编辑
